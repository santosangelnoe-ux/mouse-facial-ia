# Mouse Facial Pro - ExpoIA 2026

Sistema de accesibilidad que permite controlar el mouse de una computadora sin contacto, usando únicamente una cámara web, visión por computadora y expresiones faciales.

## Controles
- **Mover cursor:** Movimiento suave de la nariz.
- **Clic izquierdo:** Sonrisa corta.
- **Scroll vertical:** Mantener sonrisa (0.45s) + mover la cabeza arriba/abajo.
- **Clic derecho:** Abrir ligeramente la boca.
- **Arrastrar y soltar (Drag & Drop):** Levantar las cejas para agarrar/soltar.
- **Teclas globales:** `F8` para pausar/reanudar | `F9` para salir.
